## Meeting summary (email thread, 15–21 Jul 2026; planners ⇄ Ridho, cc Oi Rozak/OPAA)
**Verified current practice:**
1. Planning flow **LTP → 12M → 90D → 30D → 7D** confirmed by planners.
2. Activities originate from **approved LTP**, then pass through **"Integrated Highlight Activities"** before entering the **90D Plan**. *(This "Integrated Highlight Activities" staging step is a real practice not explicitly named in the guideline draft — candidate to document.)*
3. **Routine and non-routine** activities follow the same planning flow.
4. **Readiness assessment currently uses 4 aspects: Engineering, Material, Manpower, Permit & Regulatory.**
5. Readiness still relies on **planner judgement**; evidence stored by each planner individually.
6. **No formal definition of "Ready"** yet for each readiness aspect.

**Improvement processes proposed (from the meeting):**
- Set **activity entry criteria per planning horizon** (minimum information/detail required to enter each horizon).
- Define a **high-level "Ready" definition** for each readiness aspect (Engineering, Material, Manpower, Permit & Regulatory) — high-level is acceptable.
- **Document the planner-judgement & readiness-assessment process** in the guideline.
- **Standardize readiness criteria without removing planner-judgement flexibility.**
